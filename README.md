## 🧩 Proyectos clave (roadmap)

### 1) 📦 Optimización de inventario y rotación (ABC/XYZ)
**Problema:** exceso de stock en productos de baja rotación y roturas en productos críticos.
**Análisis:** segmentación ABC/XYZ, cobertura en días, lead time real vs planificado.
**KPIs:** Fill Rate, DOH (Days on Hand), nivel de rotura, coste de almacenamiento.
**Tecnologías:** SQL + Python (Pandas) + Power BI.

### 2) 🚛 Análisis de eficiencia de transporte y costes por ruta
**Problema:** incremento de costes de transporte y variabilidad de entregas.
**Análisis:** coste por km, ocupación de camión, entregas OTIF, rutas más/menos rentables.
**KPIs:** OTIF, coste por envío, coste por tonelada, tasa de incidencias.
**Tecnologías:** SAP data export + SQL + Power BI.

### 3) ⏱️ Predicción de retrasos en entregas (ETA Risk)
**Problema:** retrasos no anticipados en última milla y distribución regional.
**Análisis:** modelo de clasificación para predecir riesgo de retraso por franja horaria, ruta y transportista.
**KPIs:** precisión del modelo, recall en casos de retraso, puntualidad global.
**Tecnologías:** Python (scikit-learn) + Power BI para monitoreo.

### 4) 🏭 Productividad de almacén (inbound / outbound)
**Problema:** cuellos de botella en preparación de pedidos y recepción.
**Análisis:** tiempos de ciclo por operación, productividad por turno, heatmap de horas pico.
**KPIs:** picks/hora, tiempo medio por pedido, backlog diario, nivel de servicio.
**Tecnologías:** SQL + Excel avanzado + Power BI.

### 5) 💰 Control financiero logístico (cost-to-serve)
**Problema:** poca visibilidad del coste real por cliente, canal o zona geográfica.
**Análisis:** asignación de costes directos/indirectos, margen por segmento, simulación de escenarios.
**KPIs:** coste-to-serve, margen neto por cliente, ahorro potencial por optimización.
**Tecnologías:** SQL + Python + dashboard ejecutivo.

## 🧪 Estructura recomendada para cada proyecto

Para que cada caso de estudio sea profesional y fácil de evaluar:

1. **Contexto del negocio** (qué problema se resuelve).
2. **Fuente y calidad de datos** (origen, limpieza, supuestos).
3. **Métricas clave** (KPIs logísticos y de impacto).
4. **Análisis exploratorio (EDA)** con hallazgos principales.
5. **Modelo o lógica analítica** (si aplica).
6. **Dashboard final** con recomendaciones accionables.
7. **Impacto esperado/obtenido** (ahorro, servicio, productividad).
